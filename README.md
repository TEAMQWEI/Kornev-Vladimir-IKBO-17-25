# Визуализатор графа зависимостей пакетов (npm)

## 1. Общее описание

CLI-инструмент для анализа и визуализации графа транзитивных зависимостей пакетов JavaScript (`npm`) без использования сторонних библиотек и менеджеров пакетов. Приложение написано на Python 3 с использованием исключительно стандартной библиотеки.

Поддерживаются:
- чтение и строгая валидация параметров из INI-файла;
- прямое обращение к реестру `npm` по HTTP/HTTPS и разбор JSON-метаданных;
- построение транзитивного графа зависимостей итеративным алгоритмом BFS (без рекурсии) с корректной обработкой циклических зависимостей;
- тестовый режим работы с локальными файлами описания графа;
- поиск обратных зависимостей тем же итеративным BFS;
- генерация диаграмм на языке Mermaid и отображение изображения графа на экране.

## 2. Описание всех функций и настроек

### Параметры INI-файла (секция `[settings]`)

| Параметр | Тип | Описание |
|---|---|---|
| `package_name` | `str` | Имя анализируемого пакета (формат npm либо заглавные латинские буквы при `test_mode = true`). |
| `repository_url` | `str` | Базовый URL реестра npm (`https://registry.npmjs.org`) или путь к файлу тестового репозитория. |
| `test_mode` | `bool` | Режим работы с тестовым репозиторием (`true`/`false`). |
| `package_version` | `str` | Версия анализируемого пакета (например, `4.1.2`). |
| `reverse_mode` | `bool` | *(Опционально)* Вывод обратных зависимостей (`false` по умолчанию). |

### Аргументы командной строки

- `-c, --config PATH` — путь к INI-файлу (по умолчанию `config.ini`).
- `-m, --mode {config,direct,graph,reverse,visualize}` — выбор режима работы (соответствует этапам 1–5; по умолчанию `visualize` или `reverse`, если включён `reverse_mode = true`).
- `--no-display` — вывести только текст диаграммы Mermaid без открытия графического окна.

### Модули проекта (`src/`)

- `config.py` — загрузка (`load_config`) и валидация параметров INI-файла (`parse_bool`, `validate_package_name`, `validate_repository`, `validate_version`), вывод `key=value` (`format_config`).
- `semver_util.py` — парсинг и сопоставление диапазонов SemVer (`^`, `~`, `>=`, `<=`, `>`, `<`, `*`, `||`) без внешних библиотек (`resolve_version`).
- `fetcher.py` — HTTP-клиент реестра npm (`NpmRegistryFetcher`) и парсер файлов тестового репозитория (`load_test_repository`).
- `graph.py` — итеративный BFS без рекурсии (`build_graph_bfs`), построение графа npm (`build_npm_graph`) и тестового графа (`build_test_graph`), инверсия графа (`invert_graph`) и поиск обратных зависимостей (`find_reverse_dependencies`).
- `visualizer.py` — генерация диаграммы Mermaid (`graph_to_mermaid`), рендеринг PNG через `mermaid.ink` (`fetch_mermaid_png`) и вывод изображения в окне `tkinter` (`display_png_window`).
- `main.py` — точка входа CLI.
